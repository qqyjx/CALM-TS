Dataset Access Instructions¶

CALM-TS is evaluated on three benchmarks, each requiring external access. This document covers the credentialing / licensing requirements and points to the loaders in experiments/lib/data_loaders.py.

Expected layout¶

Set via CALM_TS_DATA env var, defaults to ~/.calm_ts_data/:

$CALM_TS_DATA/
├── mimic/
│   ├── windows.npy     # (12847, T, C) float32, T=60 @ 1Hz, C=8 vital signs
│   ├── labels.npy      # (12847,) int32, 8 event categories
│   └── split.json      # {"gold": [...], "unlabeled": [...], "test": [...]}
├── physionet/
│   ├── windows.npy        # (7875, T, C), T=7500 @ 250Hz, C=5 channels
│   ├── labels.npy         # (7875,) int32, 5 alarm types (legacy 5-class)
│   ├── labels_binary.npy  # (7875,) int32, true/false alarm (camera-ready)
│   └── split.json
└── yahoo/
    ├── windows.npy     # (15621, T, C), T=3600s windows, C=1
    ├── labels.npy      # (15621,) int32, binary anomaly labels
    └── split.json

1. MIMIC-III (ICU monitoring)¶

Source: PhysioNet — https://physionet.org/content/mimiciii/1.4/

Access requirements:

  1. Complete CITI "Data or Specimens Only Research" training (about.citiprogram.org) — ~4 hours
  2. Sign the PhysioNet Credentialed Health Data Use Agreement
  3. Apply for MIMIC-III access; approval typically 1–2 weeks

Preprocessing: experiments/preprocess_mimic.py consumes a flat parquet/csv export of CHARTEVENTS + diagnosis categories:

python experiments/preprocess_mimic.py \
       --input  $CALM_TS_RAW/mimic \
       --output $CALM_TS_DATA/mimic \
       --format parquet

Expected $CALM_TS_RAW/mimic/:

  • charts.parquet — columns stay_id, charttime (sec offset), HR, SpO2, SBP, DBP, MAP, RR, Temp, GCS
  • diagnoses.parquet — columns stay_id, icd_category (one of the 8 categories)

The upstream extraction (CHARTEVENTS + LABEVENTS + D_ICD_DIAGNOSES → these two parquet files) is project-specific and not redistributable; it must be done locally on the credentialed MIMIC-III source per license. The script then:

  • Slides 60-second non-overlapping windows over each ICU stay's charts
  • Aggregates each minute's per-channel mean (handles upstream sampling > 1 Hz)
  • Carries forward missing minutes within a window after the < 10% missingness gate
  • Retains windows whose stay matches one of the 8 diagnosis categories (normal, cardiac_arrhythmia, sepsis_onset, hemodynamic_instability, respiratory_failure, neurological_event, infection, other)
  • Paper target: ≈12,847 windows

License constraints: Redistribution prohibited. The windows.npy file must be regenerated locally from the approved MIMIC-III source.

2. PhysioNet Challenge 2015 (Arrhythmia Alarms)¶

Source: https://physionet.org/content/challenge-2015/1.0.0/

Access requirements: Subject to PhysioNet's Open Data License. As of 2026 PhysioNet enforces HTTP-Basic auth for bulk recursive downloads even on open datasets — log into your free PhysioNet account and pass the credentials to wget.

Preprocessing: experiments/preprocess_physionet.py requires wfdb (pip install wfdb):

# 1. Download (replace USER with your physionet.org login)
wget -r -N -c -np --user=USER --ask-password \
     https://physionet.org/files/challenge-2015/1.0.0/

# 2. Run preprocess
python experiments/preprocess_physionet.py \
       --input  physionet.org/files/challenge-2015/1.0.0 \
       --output $CALM_TS_DATA/physionet

Behaviour:

  • Walks all .hea/.mat records under --input
  • Resamples ECG_I, ECG_II, ABP, PPG, RESP to 250 Hz (linear interp; sufficient for downstream temporal-summary statistics)
  • Cuts each record into a single 30 s window centred on the alarm onset; the 5-class label (labels.npy) is the first letter of the record id (a→asystole, b→bradycardia, c→tachycardia, d→vtach, e/f→vfib/vflutter); the binary label (labels_binary.npy, used in the camera-ready paper) is the Challenge ground-truth verification flag (true vs. false alarm)
  • Missing channels are zero-filled (downstream stats handle constant arrays)
  • Camera-ready target: ≈7,875 windows; class balance for binary is 60.9% false / 39.1% true

Note (camera-ready task switch). The KDD'26 camera-ready PhysioNet column uses the official Challenge 2015 binary alarm-verification task rather than the review-version 5-class alarm-type formulation. Both label files are produced by the same preprocessor in one pass; the binary task is the one cited in Table 1 of the paper. Per-seed run artefacts under results/runs/seed{0..4}/ and the 5-seed aggregate under results/runs/seeds0_1_2_3_4/ all operate on labels_binary.npy. The legacy 5-class runs results/runs/multi5class/ and results/runs/multi5class_clinical/ consume labels.npy.

3. Yahoo S5 (Web Service Metrics)¶

Original distribution: Yahoo Webscope — webscope.sandbox.yahoo.com/catalog.php?datatype=s&did=70

Mirror used for this work: Aliyun Tianchi public mirror — tianchi.aliyun.com/dataset/88734 — chosen because Webscope DSA approval lead time exceeded our camera-ready timeline. The Tianchi archive is bit-equivalent to the Webscope distribution (A1/A2/A3/A4 sub-benchmarks). For canonical re-distribution and license terms, refer to the Yahoo Webscope link above.

Access requirements (original Webscope path):

  1. Create a Yahoo Labs Webscope account (free, academic only)
  2. Accept the dataset-specific Data Sharing Agreement
  3. Download S5 (includes A1/A2/A3/A4 sub-benchmarks); 1.3 GB archive

Preprocessing: experiments/preprocess_yahoo.py:

python experiments/preprocess_yahoo.py \
       --input  $CALM_TS_RAW/ydata-labeled-time-series-anomalies-v1_0 \
       --output $CALM_TS_DATA/yahoo

Expected --input layout (post-extraction): a directory tree containing the A1Benchmark/, A2Benchmark/, A3Benchmark/, A4Benchmark/ folders with their per-series CSVs. The script:

  • Reads every CSV, tolerating both is_anomaly / anomaly column variants
  • Concatenates per file, slices into non-overlapping 3600-step windows
  • Labels a window anomaly (1) if any flag inside is positive, else normal (0)
  • Paper target: ≈15,621 windows

License constraints: Academic-only redistribution prohibited.
